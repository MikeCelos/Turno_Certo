    Sincronização Cloud (Supabase) · Opcional

    Armazenamento Local

    Permite sincronizar escalas e configurações entre múltiplos dispositivos de forma segura. Por omissão, todos os dados são mantidos exclusivamente em armazenamento local.

    Instruções de integração Supabase e servidor de email Brevo
    1. Cria a tua conta em supabase.com e cola o URL e a Chave acima.
    2. No Brevo (brevo.com):
      • Cria uma conta gratuita (300 emails/dia).
      • Em Senders & IPs → Senders, adiciona flascocelos@gmail.com (nome: Turno Certo) e confirma no teu Gmail.
      • No menu → SMTP & API → aba SMTP, clica em Generate a new SMTP key.
    3. No Supabase (Authentication → SMTP Settings):
      • Host: smtp-relay.brevo.com · Porta: 587
      • User: [o teu login do Brevo] · Password: [chave SMTP gerada]
      • Sender email: flascocelos@gmail.com · Sender name: Turno Certo
